# City Pulse Furniture - Enhanced E-Commerce Website

A modern, fully-featured furniture e-commerce website with admin dashboard, shopping cart, and responsive design.

## 🚀 Features

### User Features
- **Modern Homepage** - Beautiful hero section with featured products and animations
- **Product Catalog** - Browse furniture with search, filter, and sort functionality
- **Product Details** - Modal view with detailed product information
- **Shopping Cart** - Full cart functionality with quantity management
- **Responsive Design** - Mobile-friendly across all devices
- **Toast Notifications** - User-friendly feedback for all actions

### Admin Features
- **Admin Login** - Secure admin authentication
- **Add Products** - Upload new furniture items with images
- **Manage Products** - Edit and delete existing products
- **Product Management** - Organize products with badges (Best Seller, New Arrival, Classic, Custom)

### Additional Pages
- **About Us** - Company information and values
- **Our Services** - Service offerings with visual cards
- **Contact Us** - Contact form with validation

## 🚀 Getting Started

1. Open `index.html` in a web browser
2. Navigate through the pages using the navigation bar
3. Browse furniture, add items to cart
4. Access admin dashboard with credentials above
